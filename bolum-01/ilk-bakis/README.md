# Bölüm 1 — Electron'a İlk Bakış

Bir pencere açan ve uçbirime Electron, Chromium ve Node.js sürümlerini yazan en küçük örnek.
Kurulumu Bölüm 2'de anlatıyoruz; Node.js kuruluysa şimdiden deneyebilirsiniz:
